FAQ

Frequently asked questions

Helpful answers regarding joining the server, rank fulfillment, and gameplay features.

How do I join on Minecraft Java & Bedrock?

Java Edition: go to Multiplayer → Add Server, and enter the server address play.solomc.net. Java uses the default port 25565, so you don't need to type a port.

Bedrock Edition (Windows 10/11, iOS, Android and consoles): go to Play → Servers → Add Server, enter the server address play.solomc.net, and set the port to 19132. Bedrock players must set the port to 19132 or the server won't show up.

Can players with non-premium (cracked) accounts join?
Yes, SoloMC fully supports both official Mojang/Microsoft accounts and non-premium (cracked) clients. Simply enter play.solomc.net and connect!
How long does it take for ranks to be delivered?
Purchases are automated and delivered via console commands within 1 to 5 minutes. Please stay connected to play.solomc.net while completing checkout.
Where do I go if I need staff assistance?
Open a ticket on the Tickets page, or join our Discord server at discord.gg/solomc and open a ticket there.
